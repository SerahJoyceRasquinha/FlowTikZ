# Examples

| File | What it is |
| --- | --- |
| `submission-review.json` | The worked example diagram. Open it with **Open** in the toolbar (or press **Load example** in the top bar) |
| `submission-review-standalone.tex` | The same diagram in standalone mode — compiles on its own in Overleaf |
| `submission-review-snippet.tex` | The same diagram in snippet mode — paste into an existing document |

To see the whole pipeline in one pass: press **Load example**, look at the code
panel, click a shape and watch its lines light up, then compare the code against
`submission-review-standalone.tex`.
